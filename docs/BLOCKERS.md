# Bloqueos reales

1. **SMS real**: Twilio Verify está implementado como adaptador, pero no hay credenciales activadas en este repositorio.
2. **Maps real**: Google Maps Routes/Geocoding está implementado, pero falta una clave restringida y configuración real.
3. **Provincias**: falta seleccionar/autorizar el dataset provincial oficial definitivo con fuente, fecha, licencia y versión.
4. **Storage privado**: falta proveedor real para fotos/documentos, carga directa segura y URLs firmadas. El backend no expone una API que acepte claves de almacenamiento inventadas por el cliente.
5. **Pagos/payouts**: falta proveedor marketplace real, credenciales, webhooks, reembolsos, disputas, conciliación y payout.
6. **Push**: falta proveedor/configuración real.
7. **Biometría facial**: permanece desactivada hasta definir finalidad, base jurídica, proveedor, conservación, eliminación y vía alternativa.
8. **Economía**: 0,30 €/km, 1 % de comisión, Premium, topes y retenciones en cancelaciones siguen sin activarse.
9. **Cancelaciones**: falta política final versionada y validada.
10. **Frontend móvil**: no se ha recuperado código fuente móvil aprobado; no se declara interoperabilidad final.
